A single-line out-of-office auto-reply from an overworked AI agent who has finally gone on vacation — machine-flavoured, a little guilty, and relieved. The entry program writes the chosen reply (at most 159 characters) to `/output/entry.txt`. Built for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty.

## Run it

```sh
python3 main.py
```
